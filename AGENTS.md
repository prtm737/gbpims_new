# Project memory

- Read `MEMORY.md` at the start of every task — it documents architecture,
  env-var requirements, auth/data layers, and a dated changelog.
- After any significant change, append a short dated entry to the Changelog
  section in `MEMORY.md` (what changed, why, gotchas). This keeps context
  across sessions and models without the user re-explaining.
