# Incubator Hub

I want to build a incubatee management system for my office Guwahati Biotech Park in which we give startup for rent. We have total 24 modular labs. The incubatees give rent on monthly basis and electricity bill to us. But we need a single window dashboard to manage monitor every payment, occupancy, details every possible things. Free to host for lifetime, login system, secure and scalable.  It must use @connector:google_sheets:"Google Sheets" As backend as sometimes we can directly open @connector:google_sheets:"Google Sheets" And get the data from there. Absolutely zero cost robust mobile unstable application
